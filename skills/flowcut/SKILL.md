# FlowCut · 口播Skill

目标是让口播更自然、连贯，而不是删字最多或时长最短。默认保留说话人的声音、原意、情绪与必要限定语，不做配音替换、改写观点或发布。

FlowCut 是项目名；在口播精剪语境中，“口播Skill”和 `koubo-skill` 是同一工作流的常用称呼。本仓库的可安装技能标识仍为 `flowcut`，显式调用使用 `$flowcut`。FlowCut Studio 的片头片尾或模块组合属于另一套流程。

## 进入任务

- 用户只要求分析时只给分析；明确要求剪辑时才导出改动版。保留原片，输出不同文件名；已有成片不覆盖。
- 确认当前这次提供的文件，不把上一版的时间轴套到新素材。记录帧率、帧数、音频采样率、画幅、起始时间、可变帧率与字幕类型。
- 先检查是否已经剪过。字幕、摘要式 ASR 经常省略口头语：没有文字命中，不等于没有残音；也不能为显得有改动而强删合法发音。
- 读 [剪辑判断与导出](references/editing.md) 再建立删剪计划。使用影视飓风参考方法时，再读 [已核对的参考要点](references/reference-video.md)。

## 按本次请求选择模式

- **重录去重**：用户要求删掉重复录制、保留后一次或挑选重说版本时，读 [重复录制与选段](references/retakes.md)。按完整语义选 take，再处理切点；不能用相同字词直接去重。
- **基础长停顿清理**：常规口播剪辑、重录去重都要读 [长停顿检查](references/pauses.md)，在选完保留版本后检查整条保留时间轴，缩短确认无信息的录制等待，包括开头、结尾和远离重录点的空白。不是只清理重录之间的空白，也不是把所有停顿都剪短。
- **语气词与节奏精修**：按下文逐项判断。基础长停顿清理不等于授权删除口头语、词内口吃、正常换气或所有句间停顿；不顺带重新配音或添加效果。
- **整体语速是独立参数**：默认保持素材原速。参考样片或个人发布习惯中的整体提速，不自动成为本 Skill 的规则，也不能代替停顿清理；只有用户对当前任务明确提出变速时才单独执行并报告，剪辑取舍仍按原速素材的语义、字头字尾和画面动作判断。
- 用户明确要求“保留停顿”“不调节奏”“只剪指定区间，其余不动”时遵从限制。仅说“删重录、保留后次”时，说明将一并清理明显空等；不再把这种要求解释为免检全片停顿。
- 还要求语气词/节奏精修时，先解决重录替代关系，再在保留片段中精修，所有决定始终记录在原片时间轴。只说“精剪”且取舍会明显影响内容时，说明拟采用的范围，不推定所有相似句都要删除。

## 口头语判断

用户常见的目标词是“就是、然后、啊、呃、我觉得”。逐处结合前后完整语义判断；用户指定列表优先，不擅自扩大成删除全部连接词。

- 无意义的起话、思考填充、紧邻重复可删；“然后”表示时间或因果推进时保留。
- “我觉得”若表达主观判断、保留不确定性，删除会改变立场，默认保留或提出可选方案。
- “就是”可能是实质性的判断或强调。不要把“不是……就是……”等结构拆坏。
- “啊/呃”需区分独立语气、词内音节、正常元音和吸气；“嗯/哈/哎”及只剩“就/是”的残片可列入复核，但不按字符一刀切。
- 高疑似、短促词、词边界模糊处，应结合第二识别结果与波形检查。ASR 时间戳是定位线索，不是切点；CTC 尖峰尤其不等于音节起止。

## 可复用工具

- [scan_ctc.py](scripts/scan_ctc.py) 只生成候选，不批准剪切。它需要本机已有的指定声学模型和运行库，并校验模型指纹；用法见 [本地分析与校验](references/local-tools.md)。不能把该模型的 50 ms 校准移用到别的模型。
- [scan_pauses.py](scripts/scan_pauses.py) 从 PCM16 WAV 的逐声道短窗能量生成未审核低能量候选；先看 `--help`，阈值和时长按录音调整。它不是人声检测器，不识别停顿意图，输出不能直接作为删剪计划；需要结合转写、声学和画面检查。详细流程见 [长停顿检查](references/pauses.md)。
- [render_cuts.py](scripts/render_cuts.py) 在适用规格下按批准的帧范围同步删剪音画，默认只预演。先查看 `--help` 与 dry-run 结果，再执行；它不自动判断语义、不自动美化跳切，也不等于完成听感验收。
- 用户提供参考视频链接时，如已有 VideoNote 工具，优先复用已完成素材；无需为了此 Skill 重装工具。先读取时间标记的文字并查看相应画面，不把标题、简介或稀疏截图当成逐秒观看。链接无法访问时说明证据缺口，不虚构参考结论。

## 完成标准

每一处变更都要能追溯到原片时间和理由；实际导出后重新核对接点、音画同步、残音、字幕完整性与帧数。对不同识别结果的分歧采取保守边界，不能用“识别到 0 次”宣称绝对无漏词。

对实际成片再做全片停顿检查，不只检查删剪接点。达到本次审查阈值的剩余空白逐条标记为已处理、明确保留或待确认，并记录理由；复查删剪后拼接成的新长停顿。阈值以内也抽查语句节奏，不能以“去重完成”或“没有低能量命中”代替节奏验收。

如果当前工具不能直接听音，说明实际使用了哪些文字、波形、图像或识别检查，不称“已逐段试听”。无法确认不会损坏相邻音节的候选先保留。

交付成片，并简短说明删改数量/时长、保留的不确定项、未采用的效果及原因；需要时附原片到成片时间映射和对照片段。用户未经要求不必面对全部中间文件。
