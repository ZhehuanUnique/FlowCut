# 口播对应画面（可选模式）

仅当用户明确要求为口播加相关画面时使用。它是口播剪辑后的配画面步骤，不把普通口播粗剪自动升级为完整视觉包装。

1. 先定最终口播与字幕时间轴，再逐段标出要配画面的论点、例子和时段。画面应在所讲内容附近进入、停留到观众足以看懂，再回到口播或切到下一段；覆盖比例、单镜头时长、横竖画幅、是否保留口播小窗，均以本次用户要求和参考样片为准，不设通用秒数。
2. 用户要求真实视频时，优先采用其提供的素材或许可条件可核对的实拍、录屏；不要用自制动画代替。核对素材来源、许可与实际画面，保留来源清单。借鉴参考视频的剪辑方式，不直接挪用其画面或背景音乐。同条成片尽量每条素材只用一次；导出前按素材源核对配画面清单，避免重复片段，也不要靠裁切、翻转或变速把同源重复伪装成新画面。素材不足时，保留口播画面或补找可授权素材，不为凑覆盖率重复铺画面。
3. 通用场景素材可以辅助理解，但不能充当特定产品功能、客户案例或事件的证据。人物、场景的文化与地域线索应贴合所讲语义和目标观众；不能仅凭人物外貌推断拍摄地，也不能用示意画面暗示它是真实案例。找不到准确且可用的片段时，保留口播画面、缩小配画面范围或向用户说明缺口，不用近似素材制造事实误解。说明性角标、字幕样式、重点高亮按本次请求决定；用户要求去掉角标时不要自行加回。
4. 依最终音轨切换画面，检查口播、字幕和插入画面的同步；已有烧录字幕尤其要注意裁切与遮挡。导出后抽查每个插入段的开头、末尾和语义对应，并确认口播声连续、原片仍保留。
