# 长停顿检查

用于口播的基础空等清理，不是机械“删静音”。常规剪辑和重录去重均须检查；用户明确不准调整停顿时，记录问题而不动它。

## 1. 检查整条保留时间轴

先完成语义选段，再扫描所有保留片段及它们拼接后的时间轴，包含：开头准备、结尾等待、句中找词/读稿、句间空等、重录以外的停顿、重录剪掉后两侧等待合成的空白。不要只看 ASR 有字的部分或仅扫描接点。

使用同源 PCM 音频，记录采样率、声道、视频实际有理数帧率与音画偏移。`scan_pauses.py` 输出未审核候选，不含批准的 `cuts`。先运行 `--help`；它只支持 PCM16 WAV，依赖 NumPy，不下载模型。

- 可从约 1.2 秒、RMS −40 dBFS 的低能量段开始筛查；这是定位起点，不是普适删除标准。低声、底噪和音乐场景需调整并比对。
- 必须补查转写词间/句间长间隙和画面等待。ASR 会漏轻声或填充词，声学阈值会漏含吸气、咳声或音乐的等待；两者不能相互替代。
- 短瞬态会拆开低能量候选。可以人工复核整段是否只是等待，但不能自动跨过短人声、轻声词或吸气并合并删除。任一声道有声音都应检查。
- CTC 尖峰、ASR 起止和能量窗都不是可靠音节边界；用完整上下句、波形、必要的第二识别及画面共同定位。

## 2. 逐处做决定

每处至少记录时间轴身份、原始候选范围、前后语句、分类、处理/保留理由、批准的原片帧范围、预计留下的间隔。

1. 明显无信息的录制等待：在安全低能量区域缩短中间空等，不碰前字尾音或后字起音。
2. 正常换气、段落分界、问答、悬念/强调、演示动作或需要阅读画面的时间：按实际用途保留；长也不必删。
3. 疑似轻声、词边界不明、音乐连贯性或画面动作冲突：先保留并说明，不能为满足时长指标强剪。

没有一个固定的“剩余静音长度”适合所有人。快速解说可试句中约 0.25–0.45 秒、普通句间约 0.4–0.7 秒、分段约 0.7–1.0 秒；这些仅为试听/复核起点，不是硬阈值。要计入保留的吸气及两边已有间隔，不能把两侧各留一秒误算成一秒。开头保留自然起势，结尾保留完整尾音和必要手势。

切点不统一外扩，不裁轻辅音，不用变速来代替清理等待。不强求全部小于阈值，也不为少剪而留下已确认的多秒空等。

## 3. 时间映射与画面

如果在“已去重的审核音轨”上发现候选，先用保留区间映射回原片帧号。候选跨已有切口时分段映射，再与已批准的原片删剪范围求并集；只合并相接或重叠范围，不把中间未审查内容一并删除。记录映射证据，禁止把成片秒数直接当原片秒数。

一次从原片或无损同时间轴工作副本渲染，避免从上一版有损成片再编码。检查接点眼神、姿态、嘴形；避免保留一两帧闪跳，不为掩盖硬切擅加裁切、特效或无关 B-roll。

## 4. 导出后的闭环

- 解码实际交付文件重新扫整条音轨；不是只扫渲染前的计划音频。
- 对剩余达到审查条件的候选逐一记录处理结果或明确保留理由；抽查阈值以下的间隙及转写长空白。
- 核对新接点完整语义和字头字尾、音画同步、帧数/采样数、字幕与尾音。每处长停顿减少都要有可追溯证据。
- 用导出的真实帧数报告额外减少时长，区分停顿组数与合并后的实际删剪区间数。没有声学命中不等于完全没有停顿；没有直接听音能力时如实说明检查手段。
