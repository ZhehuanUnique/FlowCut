# 剪辑判断与导出

## 1. 候选到批准

以原片时间轴保存候选：`start_frame`、`end_frame`（左闭右开）、目标词/气口、前后文、保留或删除理由及边界证据。不要从已剪时间反复累计换算。

文字中的目标串需要语义复核；波形低能量段也可能含轻辅音。对难点检查原速前后至少一句话，必要时看频谱、逐字声学峰和第二识别结果。把字头、爆破音、词尾拖音全部留在说话片段内，再在相邻低能量区域确定边界；不得统一向外多裁几十毫秒。

## 2. 气口与停顿

- 分辨急促吸气、缓慢呼气、口腔噪音与有意义的语音。获准气口/节奏精修时，可优先检查突出的吸气；与字音重叠的气息不能整段切走，可保留或局部衰减。仅重录去重加基础空等清理时，把吸气纳入切点与剩余间隔核算，不默认删正常换气。
- 保留问答、转折、分段与强调的停顿。过长无意义空白可缩短，但不要消灭全部呼吸与留白。
- 按 [长停顿检查](pauses.md) 做全片候选清单、逐处取舍和导出后复扫。开头准备、结尾等待、读稿空等与重录剪除后新拼出的空白都在审查范围；只扫描低音量不足以识别含底噪、音乐或吸气的等待。
- 有同一场景的真实 room tone 时，可以在需要留白的接缝下平滑衔接；没有独立环境声时，不假定某段低音量就是纯环境声，不把吸气、人声或变化的背景音乐循环为底噪。
- 消除接点突变可用短淡入淡出或实际有重叠的交叉淡化。先避开语音再处理；3–10 ms 只是抗爆音试验范围，不是所有素材的强制参数。更长淡化可能吃掉辅音或制造可闻空洞。
- 把“对切点做微淡化”与“连续环境声铺底”分开描述，前者不等于后者。

## 3. 跳切与字幕

首先比较切前和切后的嘴形、眼睛、头部位置、手势以及字幕状态。同一安静区内，边界可微调几帧，使动作接续自然，前提是不碰字音。

对已剪过的素材，还要核对原有切点。新切口与旧切口之间只剩一两帧会形成闪跳；应把范围安全地对齐到已有切点，或放弃这处不划算的删剪，不能单凭像素差或低能量分数选点。

画幅足够、清晰度允许且字幕安全时，才考虑切换较近景别；在句子/语义段之间切换，不要每个口头语都推拉一下。1.33–1.6 倍是参考视频的做法，不是默认参数。近景、低清、烧录字幕容易被裁掉时不采用。

动作差异很大且已有相关、获准使用的 B-roll，可覆盖接点；不能擅自下载别人的片段或生造证据性画面。缺合适素材时，保留自然硬切或说明需要额外素材，不用叠化制造重影。

烧录字幕随画面同步剪切，不能像独立字幕那样无损重排。避免长时间保留被删词的字幕或截掉字幕本身；用户未要求时，不擅自遮挡、重做、替换字幕语言或去除水印。

## 4. 时间轴与导出

- 整体播放速度与删剪计划分开记录。用户未对当前任务明确要求变速时保持原速；不能从参考片、历史成片或个人习惯反推出通用倍速，也不能用变速掩盖尚未处理的空等或节奏问题。
- CFR 用实际有理数帧率，不把 29.97 当成 30。VFR 先明确转换方案或采用支持原时间戳的流程；不能盲猜固定帧率。
- 视频删除范围为原片帧区间 `[start_frame, end_frame)`；音频按同一时间映射计算采样边界，保留声道与采样率。若音频有非零起始偏移，先处理偏移，不能从零生拼。
- 重叠范围合并；跨越间隙合并可能删除额外内容，必须单独批准。不得自动扩大已审核范围。
- 音频交叉重叠会改变时长，必须连同视频映射一起核算。以保持总长度不变的局部增益淡化替代时，也要明确它不是 crossfade。
- 保留画幅、帧率、原有字幕与颜色解释；HDR、旋转元数据、多音轨或特殊时基需要单独处理，不能由仅支持普通 SDR MP4 的工具强行导出。

## 5. 验收

校验原片未被覆盖、删去帧数、输出帧数、音频采样总数及容器时长；AAC 尾部填充与时间戳需结合解码结果判断，不用 `-shortest` 隐藏同步问题。

对实际导出版本复核每一个新接点；检查相邻字没有被截断、没有新增明显卡顿、画面与嘴形同步、字幕没被裁切。必要时生成短前后对照片段。对照需保持音量/速度一致，方便用户判断。

用独立识别或第二遍声学扫描检查目标词及边界上下文，不把字幕正确当成音轨干净。仍不能确认的地方在交付中说明，不能声称做过当前工具不支持的真人听审。

对实际成片的整条音轨再跑停顿候选扫描并检查转写间隙，对每处剩余长停顿说明用途或不确定性。无候选仅代表未命中这次声学条件，不代表不存在等待或节奏问题。
